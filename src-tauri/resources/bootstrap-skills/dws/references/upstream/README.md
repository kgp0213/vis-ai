# DWS command references

These selected command references come from the DWS Open Edition v1.0.51
`mono` Skill distributed with DingTalk Workspace CLI. They are documentation
only and are loaded on demand by the Visionox `dws` Skill.

The packaged DWS binary and its `--help` output remain authoritative. These
files never override Visionox read-only tool limits, credential isolation, or
the requirement to obtain explicit confirmation before external side effects.

No portable `.dws` identity, application state, token, log, Python script, or
user-specific data is included in this directory.
