# Basic Skill Example

This is a small built-in reference skill. Use it as a template for folder layout and frontmatter style.

Expected layout:

```text
basic-skill-example/
  SKILL.md
  README.md
  scripts/
    hello.js
```

Run the sample script with:

```bash
node scripts/hello.js
```
