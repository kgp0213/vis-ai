## 二、影响所有技能的共性问题

### P0：`/skill` 斜杠命令对所有 40 个技能都不可用

`/skill` 在命令元数据表（launcher.mjs:6139）中注册了，但**没有 dispatch handler**。输入 `/skill brainstorming` 返回"ℹ️ 未知命令: /skill"。`/help` 输出和系统提示词技能索引都宣传了这个命令。

用户唯一可用路径是自然语言让 AI 自动调 `run_skill`，但这没有被文档说明为推荐方式。

### P1：桌面版未注册 subagent runner

`registerSkillTools` 调用时未传 `subagentRunner`，`spawn_subagent` 未注册。内置子代理技能（explore/research/review/test/security-review）在桌面版不可用，仅在 TUI CLI 中可用。当前 40 个 bootstrap 技能都没声明 `runAs: subagent`，所以是潜在风险而非实际故障。

### P1：Provenance 不完整

40 个技能中 7 个 `verified`、33 个 `partial`（license 未确认）。superpowers 和 ECC 导入的技能 MIT License 在源码树中存在但未随部署打包，`THIRD_PARTY_NOTICES.md` 也未提及。

### P2：部署目录漂移

`~/.visionox/skills/` 有 27 个非 bootstrap 技能（docx/github/weather/xlsx 等）和大量 `.bak-*` 备份，`installBootstrapSkill` 每次保留 3 个备份但不清理已删除/改名的用户技能。

## 三、❌ BROKEN（1 个）

### pdf

| 问题 | 说明 |
|------|------|
| `PDF_SKILL_DIR` 未设置 | SKILL.md 中引用 12+ 次 `bash "$PDF_SKILL_DIR/scripts/..."` 和 `python3 "$PDF_SKILL_DIR/scripts/pdf.py" ...`，但 `run_skill` 和 launcher 都不设置此环境变量，所有脚本调用路径为空 |
| setup.sh 平台不兼容 | `setup.sh` 是 bash 脚本，Windows 无法直接运行 |
| 依赖链庞大 | Python 3 + pikepdf/pdfplumber/pypdf/reportlab/pymupdf + Playwright/Chromium + 可选 Tectonic/LibreOffice/CJK 字体 |

**修复方案**：在 `run_skill` 返回结果中注入实际部署路径（`~/.visionox/skills/pdf/`），或修改 SKILL.md 用相对路径替代 `$PDF_SKILL_DIR`。

## 四、⚠️ PARTIAL（12 个）

### 4.1 Claude Code 专有引用（9 个）

这些技能引用了 Claude Code 独有的工具和概念。模型能理解文字意图，但字面工具调用会失败。

| 技能 | 引用了什么 | Visionox 对应 |
|------|-----------|--------------|
| codebase-onboarding | "Claude Code" 措辞 | 无 |
| context-budget | Task tool / CLAUDE.md / agent model | run_skill / AGENTS.md |
| dispatching-parallel-agents | `Task("...")` 调用 | spawn_subagent（桌面版未注册） |
| executing-plans | `TodoWrite` | todo_write |
| requesting-code-review | Task tool + code-reviewer subagent | 无对应 subagent runner |
| search-first | "researcher agent" | explore/research（桌面版不可用） |
| subagent-driven-development | TodoWrite + subagent dispatcher | 同上 |
| using-superpowers | `Skill` tool / TodoWrite | run_skill / todo_write |
| writing-skills | `~/.claude/skills` 路径 + Graphviz 依赖 | `~/.visionox/skills` |

**修复方案**：批量编辑这 9 个 SKILL.md，做以下替换：
- `Skill tool` / `Use the Skill tool` -> `run_skill`
- `Task("...")` -> `spawn_subagent`
- `TodoWrite` -> `todo_write`
- `~/.claude/skills` -> `~/.visionox/skills`
- `CLAUDE.md` -> `AGENTS.md`

### 4.2 依赖缺失（3 个）

| 技能 | 缺失依赖 | 说明 |
|------|----------|------|
| md-to-pdf-cjk | Python + reportlab | 需 `pip install reportlab`，SKILL.md 未提示 |
| systematic-debugging | `find-polluter.sh`（bash） | 核心技能可用，辅助脚本 Windows 不可直接运行 |
| basic-skill-example | 弱描述 | demo 技能，描述非任务触发型，不会被 AI 自动选用 |
