# Visionox-Whale 用户使用指南

> 适用版本：1.28.0
> 第一次使用建议先读[快速上手](快速上手.md)

## 界面总览

打开 Visionox-Whale 后，左侧导航栏分两组：

**工作区**

| 入口 | 用途 |
|------|------|
| 对话 | 日常与 AI 对话的主界面 |
| 会话 | 查找、预览、继续或整理历史对话 |
| 文件 | 集中查看最近生成和打开的文件 |
| 任务 | 创建定时任务，自动生成简报、周报等 |
| 概览 | 查看当前状态、费用和数据概况 |

**高级**

| 入口 | 用途 |
|------|------|
| 记忆 | 管理记忆、编辑 AI 身份（Soul） |
| 技能 | 查看和管理已安装技能 |
| 工具 | 查看可用工具 |
| MCP | 查看 MCP 服务状态 |
| 语义 | 构建本地语义索引 |
| 设置 | 工作场景、搜索引擎、模型凭据等配置 |

## 工作空间

输入框下方「工作空间」按钮显示当前目录和最近使用的工作空间（最多 10 个）。选择后下一次新建对话时切换，不打断当前对话。历史条目右侧的「×」只移除记录，不删除目录。

---

## 记忆

AI 能记住你的偏好、项目信息和临时上下文。在左侧「高级 -> 记忆」集中管理。

### 四类记忆

| 记忆类型 | 适合记住什么 | 保留多久 |
|----------|------------|----------|
| 会话记忆 | 当前对话的临时上下文 | 当前对话，`/new` 清除 |
| 场景偏好 | 某个工作场景下的习惯 | 跨会话，仅该场景可见 |
| 全局记忆 | 身份、称呼等长期偏好 | 跨所有会话和项目 |
| 项目记忆 | 当前项目的关键信息 | 跨会话，仅该项目可见 |

### 怎么让 AI 记住

直接在对话里说，关键是用对措辞：

| 想要的效果 | 这样说 |
|-----------|--------|
| 所有场景都记住 | `请长期记住：我的称呼是张三` |
| 只在当前项目记住 | `请长期记住到当前项目：发布流程是先打 tag 再构建` |
| 只在当前场景记住 | `请在编程场景下长期记住：我用 Vite + pnpm 构建` |
| 当前对话临时记住 | `请临时记住：本轮按方案 B 处理` |

避免只说"记一下这个"--AI 不知道该存到哪里。

### 管理记忆

- **查看**：在「记忆」面板按范围筛选（全部 / 全局 / 当前项目 / 工作场景 / 当前会话 / AI 身份 / 回收站）。
- **编辑和删除**：点开记忆详情编辑或删除；删除的长期记忆和场景记忆先进入回收站，30 天内可恢复或永久删除。
- **应用到当前对话**：保存后如果页面提示"仍在用旧记忆"，可点「立即应用到当前对话」；否则下次 `/new` 时自动生效。

### 编辑 AI 身份（Soul）

在「记忆」面板选「AI 身份」，可改 AI 名称和行为准则。支持基础模式（分段填写）和高级模式（编辑原文）。保存前可预览最终注入效果，可恢复默认值或历史版本。

## 工作场景

切换场景后立即生效，无需 `/new`。

| 场景 | 适合做什么 | 默认规则 |
|------|-----------|----------|
| 通用 | 日常问答、资料梳理 | 通用规范 |
| 编程 | 代码阅读、修复、重构、测试 | 通用 + Rust + TypeScript + Python |
| 办公 | 文档、表格、PDF、PPT | 通用规范 |
| 设计 | 界面体验、前端布局 | 通用 + Web |

在输入框上方切换，或在「高级 -> 设置 -> 工作场景」中选择。每个场景的记忆和规则独立保存，互不干扰。

## 编辑模式

输入框上方可切换三档，控制 AI 操作文件和命令的限制：

| 模式 | 文件操作 | Shell 命令 | 适合 |
|------|---------|-----------|------|
| **auto**（推荐） | 工作区内自动生效 | 受白名单限制 | 日常使用，安全省事 |
| yolo | 工作区内自动生效 | 自动运行 | 信任的批量任务 |
| admin | 无限制 | 无限制 | 需要系统级操作时临时切换 |

> admin 模式下 AI 可访问磁盘任意位置和执行任意命令，界面会显示红色警告。普通使用建议保持 auto。

| 命令 | 作用 |

## 技能

技能是预设的专项能力，AI 会根据任务自动选用，也可以手动指定。

- **查看技能**：左侧「高级 -> 技能」
- **输入框调用**：输入 `@技能名` 或用 `/技能名 任务描述`，例如 `@weather 查明天北京天气`
- **技能菜单**：输入框下方「🔧 技能」按钮选择
- **随程序提供的技能**：删除后进入停用状态，点「修复 Skill 环境」可恢复

`tavily-search` 随程序提供，使用内置 Node.js 运行，无需另装 Python。首次使用时输入框上方会弹出凭据设置栏，填写 API Key 后保存即可。

## 办公文档处理

办公场景下，AI 通过内置 OfficeCLI 直接操作 Word、Excel 和 PowerPoint，不需要安装 Microsoft Office。

### 能做什么

| 格式 | 示例说法 |
|------|---------|
| Word | `帮我创建一个 Word 文档，写一份会议纪要` |
| Excel | `创建一个 Excel 表格汇总本月销售数据` |
| PowerPoint | `生成一份项目周报的 PPT` |
| PDF | `总结 D:\资料\说明书.pdf`、`把这份 Markdown 转成 PDF`、`创建一份 PDF 报告` |

直接描述需求即可，AI 会自动选择合适的工具。读取现有 PDF 使用随软件提供的 PDF.js，不依赖 Python；
OfficeCLI 只处理 Word、Excel 和 PowerPoint。受保护文档第一次准备后会获得稳定引用，切换工具或临时副本
缺失时可从原始文件重新准备，不需要复制到工作区。`md-to-pdf-cjk` 仅用于 Markdown 生成 PDF，不是 PDF 阅读器。

把现有 PDF、Word、Excel、PPT、HTML、Markdown、CSV 或文本“整理并保存为 Markdown”时，程序会创建
可恢复的后台任务。默认结果是“开头摘要 + 完整正文”，不会用摘要替代原文。输入区下方的“后台任务”可
查看进度和当前模型，并可暂停、继续、取消、预览或只重试失败部分。主模型无法可靠处理某个区块时，程序
可探测其他已配置模型并只重做该区块；无法分析的图片、图表或失败内容会保留位置/原文并明确标记复核。
只有明确要求“简要摘要”时才会生成有损的精简版本。

### 复杂操作建议

编辑复杂 Office 文档时，让 AI 先检查当前文档状态再小批量修改，能减少出错和往返；只做整理转换时直接
说明输出文件即可，不需要手动指定分批方法。详细工作流和故障排查见 [OfficeCLI 办公指南](OFFICECLI_GUIDE.md)。

## 定时任务

在「任务」页面创建定时任务，让 AI 按设定时间自动执行。三类任务：

| 类型 | 做什么 |
|------|--------|
| 普通提示词任务 | 按计划执行一段提示词，自动生成结果 |
| Skill 模板任务 | 使用预设模板（如 V来家简报、周报素材）自动整理 |
| 会话报告任务 | 基于历史会话生成日报、周报或年报 |

### 创建方法

1. 打开「任务」，点「新建」。
2. 选择任务类型，填写提示词或选择模板。
3. 设置执行时间和频率后保存。

任务成功后可在任务页面直接预览结果。需要长期保存的报告可导出为 Markdown 文件。

### V来家定时整理

V来家提供 6 个只读整理模板（每日简报、主题合并、会议行动项、周报素材、专题调查、日志核查），详细用法见 [V来家操作指南](V来家操作指南.md)。

## 模型与凭据

### 切换模型

输入框下方「模型」按钮选择服务商和模型。外部 DeepSeek 可选 auto/flash/pro 预设。

### 配置凭据

在「高级 -> 设置 -> 模型服务凭据」中操作：

1. 选择服务商。
2. 填入 API Key（和 Base URL，如需更换地址）。
3. 点「检测 API」，通过后才能保存。
4. 保存后点「检测全部模型」，通过后即可对话。

> 检测失败不会覆盖旧配置，可放心测试。

### 导入配置

新电脑可通过 JSON 文件批量导入服务商和模型配置。在模型面板选择 JSON 文件，确认预览后导入。日常更换 Key 或地址用设置页即可，详见 [API Key 维护指南](API-Key维护与更新指南.html)。

## ECC 编码规范

ECC 是面向编程场景的编码规范注入层，内置 22 种语言/框架的规则包。办公和通用场景默认只启用通用规范，编程场景额外启用 Rust、TypeScript、Python 规则。

- **查看当前规则**：对话中输入 `/ecc`
- **列出全部规则包**：`/ecc list`
- **启用规则包**：`/ecc add golang`（`go` 可作为 `golang` 的别名）
- **停用规则包**：`/ecc remove golang`

也可以在「高级 -> 设置 -> 默认配置 -> ECC 编码规范」中勾选。修改后立即生效。用户自己的长期规则放在 `~/.visionox/rules/` 下，不会被 ECC 升级覆盖。

## 常见问题

**切换工作场景后感觉没变化？**
输入 `/new` 开启新对话，新场景的提示词和规则会完全刷新。

**编程场景记住的内容，切换到通用能用吗？**
不能。场景记忆按场景隔离。如需跨场景生效，用全局记忆（`请长期记住：...`）。

**记忆有长度限制吗？**
场景记忆最多 60 条，注入前 8 条。会话记忆单条 2000 字符、总量 6000 字符。全局和项目记忆按完整条目控制，不会从中间截断。

**OfficeCLI 报错怎么办？**
确认目标文件没被 Word/Excel 占用，路径可访问。详细排查见 [OfficeCLI 办公指南](OFFICECLI_GUIDE.md)。

**如何关闭记忆功能？**
设置环境变量 `VISIONOX_MEMORY=off`。
