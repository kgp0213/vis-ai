# Visionox-Whale 用户使用指南

> 适用版本：Visionox-Whale 1.28.0

---

## 一、记忆系统使用

Visionox 提供三层记忆体系，让 AI 记住你的偏好、项目事实和临时上下文。记忆按范围和生命周期分层，不同工作模式下的记忆互不干扰。

### 1.1 记忆类型速览

| 记忆类型 | 何时使用 | 生命周期 |
|----------|----------|----------|
| **会话记忆** | 临时记住当前讨论的上下文 | 当前对话（`/new` 清除） |
| **模式偏好记忆** | 让当前模式记住工作习惯 | 跨会话，仅当前模式可见 |
| **全局记忆** | 让 AI 始终记住身份/偏好 | 跨所有会话和项目 |
| **项目记忆** | 记住当前项目的关键信息 | 跨会话，仅当前项目可见 |

### 1.2 对话中存储记忆

| 目标 | 推荐说法 | 存储位置 |
|------|----------|----------|
| 跨项目长期事实 | `请长期记住：我的常用称呼是张三` | `~/.visionox/memory/global/` |
| 当前项目专属知识 | `请长期记住到当前项目记忆：发布流程是先打 tag 再构建` | `~/.visionox/memory/<project-hash>/` |
| 当前场景回答习惯 | `请在编程场景下长期记住：我习惯用 Vite + pnpm 构建项目` | `~/.visionox/mode-memory/{mode}.json` |
| 临时上下文 | `请临时记住：本轮先按方案 B 处理` | 进程内存 |

> **技巧**：避免只说"记一下这个"。如果内容要跨所有场景保留，使用"长期记住"；如果只应在某个工作场景保留，使用"在编程/办公/设计场景下长期记住"。

### 1.3 管理记忆

- **查看记忆**：在左侧「高级 → 记忆」集中查看全局、当前项目、工作场景、当前会话记忆和 AI 身份。列表会标明实际注入状态、优先级和诊断提示。
- **编辑和删除**：在记忆详情中结构化编辑或删除；删除前会要求确认，删除后可从「回收站」恢复。工作场景记忆还可移动、复制和批量启停或删除。
- **编辑 Soul**：在「AI 身份」中使用基础字段或高级原文编辑 AI 名称与 `soul.md`，可预览最终注入、恢复默认值或历史版本。Soul 不提供删除。
- **应用修改**：保存只保证内容写入磁盘。当页面提示当前上下文仍在使用旧记忆时，可在回答空闲时选择「立即应用到当前对话」；否则在下一次 `/new` 或上下文重建时生效。
- **项目规则文件**：项目根目录中的 `AGENTS.md`、`AGENT.md`、`agent.md`、`CLAUDE.md`、`claude.md` 和 `visionox.md` 会同时作为项目规则读取；`REASONIX.md` 不参与读取。
- **清理项目记忆**：「清除所有项目记忆」。

### 1.4 记忆优先级

AI 构建提示词时的注入优先级：

1. **高优先级**（标记为重要）→ 作为硬约束
2. **模式偏好记忆** → 按优先级排序，取前 8 条
3. **全局记忆** → 注入索引；高优先级条目额外注入全文
4. **项目记忆** → 注入索引；高优先级条目额外注入全文
5. **会话记忆** → 追加在末尾

## 二、工作模式

### 2.1 切换模式

在设置页的"工作场景"下拉框中选择，或通过 `/` 命令切换。切换后即时生效，无需 `/new`。

| 模式 | ID | 适合做什么 |
|------|-----|-----------|
| 通用 | `general` | 日常问答、资料梳理、轻量排查 |
| 编程 | `coding` | 代码阅读、修复、重构、测试、构建 |
| 办公 | `office` | 文档、表格、PDF、PPT、格式转换 |
| 设计 | `design` | 界面体验、前端布局、视觉风格 |

### 2.2 模式记忆隔离

每个模式有独立的记忆库，存在 `~/.visionox/mode-memory/` 下：

```
~/.visionox/mode-memory/
├── general.json       # 通用模式记忆
├── coding.json        # 编程模式记忆
├── office.json        # 办公模式记忆
└── design.json        # 设计模式记忆
```

在编程模式记住的内容不会跑到办公模式，反之亦然。

## 三、`/learn` 学习命令

### 3.1 技能萃取 `/learn skill`

把项目文档目录快速变成可复用 Skill：

```
/learn skill ./docs/api api-design-guide
```

Visionox 会扫描目录文本文件 → 调用 LLM 提炼规则 → 生成 `SKILL.md` → 安装到 `~/.visionox/skills/`。

### 3.2 项目 Onboarding `/learn project`

扫描当前 workspace，生成或更新项目记忆文件：

```
/learn project my-project
```

### 3.3 知识库索引与问答

```
/learn index ./docs          # 为目录构建语义索引
/learn ask 如何配置 MCP？     # 基于已索引内容问答
```

### 3.4 导师模式 `/learn tutor`

| 风格 | 行为 |
|------|------|
| `socratic` | 不直接给答案，通过提问引导 |
| `hint` | 提供提示，把复杂问题拆成小步骤 |
| `pair` | 结对编程伙伴，提出选项和权衡 |
| `off` | 关闭导师模式 |

导师模式为会话级，`/new` 后自动清除。

### 3.5 学习追踪 `/learn track`

```
/learn track on              # 主动学习模式：AI 穿插提问
/learn track senior          # 资深工程师模式：要求解释设计取舍
/learn track off             # 关闭学习模式
/learn track stats           # 查看概念库统计
/learn track due             # 今日到期概念
/learn track add <概念>       # 手动添加概念
/learn track review <概念> <again|hard|good|easy>  # 记录复习结果
```

使用 SM-2 间隔重复算法调度复习，概念库存储在 `~/.visionox/learn-track.json`。

## 四、OfficeCLI 办公

办公模式下，Visionox 默认使用 OfficeCLI MCP 处理 Word/Excel/PPT 操作。

### 支持的操作

- **Word (.docx)**：创建文档、读写内容、格式设置
- **Excel (.xlsx)**：创建表格、读写数据、公式计算
- **PowerPoint (.pptx)**：创建演示文稿、添加幻灯片

### 配置

启动时自动发现内置 `officecli.exe`。如需手动指定路径：

1. 打开 `%USERPROFILE%\.visionox\config.json`
2. 在 `mcp` 数组中添加：`"officecli=你的路径/officecli.exe mcp"`
3. 重启 Visionox

## 五、常用操作

### 5.1 剪贴板粘贴

- **图片/截图**：复制后按 `Ctrl+V` → 自动添加为附件
- **文件/文件夹**：从资源管理器复制后按 `Ctrl+V` → 自动贴入完整本地路径

### 5.2 模型切换

- **预设切换**：对话框上方 auto/flash/pro
- **模型面板**：底部「🤖 模型」按钮 → 选择具体模型
- **JSON 导入**：模型面板中选择 JSON 文件批量导入 Provider 配置

### 5.3 会话管理

- **新建对话**：输入 `/new` 重置上下文
- **历史会话**：导航栏「会话」→ 查看/删除/继续历史会话
- **会话恢复**：点击「加载并继续会话」恢复历史对话

### 5.4 编辑模式

对话框右下角切换：review → auto → yolo → admin

## 六、常见问题

**Q：切换工作模式后为什么感觉没变化？**
A：切换模式后系统会立即重建 loop，新模式的提示词、技能和规则即时生效。如果感觉没变化，可能是当前对话仍在使用旧上下文，输入 `/new` 开启新对话即可完全刷新。

**Q：编程模式记住的内容切换到通用模式能用吗？**
A：不能。模式偏好记忆按模式隔离。如需跨模式生效，请使用全局记忆。

**Q：记忆内容有长度限制吗？**
A：模式偏好记忆最多 180 字符，超长内容会被自动截断；每个场景最多保存 60 条，提示词选择前 8 条启用记忆。全局和项目长期记忆按完整条目控制提示词预算，不会从条目中间截断。

**Q：如何关闭记忆功能？**
A：设置环境变量 `VISIONOX_MEMORY=off` 可禁用所有记忆注入。
