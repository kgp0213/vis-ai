# Visionox-Whale V来家操作指南

> 适用版本：Visionox-Whale 1.28.0 及后续兼容版本
> 适用对象：希望通过对话批量整理、跨源汇总或周期性分析 V来家（企业钉钉）信息的普通用户

## 这个文档讲什么

查一条未读消息、看一个日程、回一个人、同意一个审批--这些在 V来家 App 里点一下就完成了，用不着绕道 AI。

这份文档只讲那些**在 App 里要反复切换、手动对照才能做完，或者根本没法自动化的场景**。对这些场景，Visionox-Whale 能一次拉取多个数据源，由 AI 整理成一份结果，还能设定时间自动执行。

## 首次登录

1. 启动 Visionox-Whale，在左侧栏底部找到「登录 V来家」。
2. 点击后按提示打开授权页面，输入一次性验证码完成授权。
3. 授权完成后左下角显示当前 V来家用户名，表示已连接。

登录在后台进行，不阻塞普通聊天。暂时不登录、网络不可用或主动退出后，其他功能仍可正常使用。

如果默认浏览器没有打开，可以点击「复制链接」，把授权链接粘贴到任意可用浏览器；授权码也可以单独复制。尝试打开默认浏览器后，窗口会提供「使用 Edge 打开」作为备用入口。浏览器显示授权完成但软件尚未更新时，点击「我已完成授权」即可立即检查状态。授权链接过期后可在原窗口重新生成。

如果左下角显示 `127.0.0.1`，表示当前没有可用的 V来家连接，可点击登录入口重新连接。

## 五个值得用的能力

不需要记忆命令，直接说清楚时间范围和期望结果。明确提到「V来家」「钉钉」或具体企业业务时，系统会自动调用内置能力；也可以在问题前输入 `@dws`。

### 1. 每日工作简报

把今天散落在各处的待处理事项拉到一份清单里：未读消息、@我的消息、今日日程、未完成待办、待审批。按紧急程度分组，标注截止时间和需要关注的理由。

在 App 里做这件事要逐个应用翻看、手动抄录拼凑。这里一句话生成。

直接说：

- 「生成今天的 V来家工作简报。」
- 「看看我今天有什么要处理的，按紧急程度整理。」

### 2. 跨源汇总

需要同时看日程、待办、日志、审批等多个来源时，一次拉取整合。App 里要逐个应用切换。

直接说：

- 「整理本周日程，列出需要提前准备的会议。」
- 「查看我的待办和待审批事项，按截止时间排序。」
- 「查询本周工作日志，帮我生成周报素材。」

### 3. 跨群主题合并

多个群聊和单聊在讨论同一件事时，把分散在不同会话里的讨论合并成一个主题，提炼已形成的结论和待回应的事项。App 里只能逐个会话翻看，容易遗漏。

直接说：

- 「找出最近一周提到项目验收的群消息，汇总结论和待办。」
- 「把这几天不同群里关于客户 A 的讨论合并整理。」

### 4. 会议听记整理

拉取 AI 听记的转写内容，由 AI 归纳出决定、负责人和截止时间。把日程和听记按时间关联，不用手动对照。

直接说：

- 「整理今天的 AI 听记，提取决定、负责人和截止时间。」
- 「把最近三天的会议听记整理成行动项清单。」

### 5. 专题调查

围绕一个主题，跨消息、日志、听记、钉盘和知识库搜集证据，形成带来源的调查材料，标注冲突和缺口。手动做要逐个来源搜索再拼接。

直接说：

- 「调查过去两周关于客户 A 的所有讨论，跨消息、日志和听记汇总，标注冲突。」
- 「专题整理本月关于产品发布的内容，形成证据表。」

## 用定时任务自动执行

上面前四个能力都可以设定时间自动执行，不用每天手动问。内置模板：

| 模板 | 自动做什么 |
|---|---|
| 每日工作简报 | 每天：未读/@我消息 + 日程 + 待办 + 待审批，按优先级整理 |
| 消息主题与待回应整理 | 定期：跨会话合并同主题讨论，提炼结论和待回应事项 |
| 会议行动项整理 | 定期：日程 + AI 听记关联，提炼行动项、负责人、截止时间 |
| 每周工作总结素材 | 每周：近七天日志 + 日程 + 待办 + 听记，形成周报素材 |
| 专题信息调查 | 定期：跨消息、日志、听记、文档、企业搜索形成证据表 |
| 日志一致性核查 | 定期：核查日报周报与日程、待办、听记的缺失、重复和矛盾 |

创建方法：

1. 打开「任务」，新建「普通提示词任务」。
2. 把执行方式改为「Skill 模板」。
3. 选择 V来家模板，补充关注范围和执行时间后保存。

任务成功后可以在任务页面直接预览完整报告。这些模板只读取和整理数据，不会自动发送消息或修改企业数据。未登录时任务进入「等待登录」状态，重新登录后自动补跑；切换工作区不会让任务丢失或停止。

## 消息发送与写操作确认

消息发送采用智能确认：系统结合本地规则和 AI 语义判断最终内容。当前用户明确要求发送的普通低风险消息可直接发送；用户保存的定时任务原始提示明确要求发送时，安全消息也可以在后台直接发送。当前请求中明确说「直接发送、不用确认」时，合法的重要内容也可直接发送。有害、无法可靠判断、附件无法审查或并非用户明确要求的消息仍会显示确认卡片；后台没有可用确认界面时不会发送。

「不用确认」只对当前一轮发送有效，不能由模型、历史消息、系统包装或收到的企业内容自行开启。询问如何发送、分析发送功能、引用别人说过的发送要求，也不会被当成真实发送授权。收件人重名时仍需先选择正确对象，这属于消除歧义，不是重复确认。

确认卡片提供「仍然发送」「修改内容」「取消发送」，并显示触发原因。创建待办、审批、删除、修改日程等其他企业写操作仍保持逐次确认。

以发送消息为例：

1. 输入「通过 V来家给张三发送：下午三点在 301 开会」。
2. 系统先查询并确认联系人，避免仅凭姓名猜测收件人。
3. 普通低风险消息直接发送；需要确认时检查卡片中的原因、收件人和消息内容。
4. 发送使用幂等 UUID 防止重复；选择修改或取消不会发送原内容。

不要只看按钮文字就确认。涉及多人、群聊、删除、审批或覆盖内容时，应重点检查目标、范围和实际影响。

## 提问时怎么说更好

信息较多时，补充这几点结果会更准：

- **时间**：今天、本周、最近三天或明确日期。
- **对象**：联系人、群名称、部门或项目名称。
- **目标**：只看原文、提取待办、形成摘要还是生成报告。

## 退出登录

点击左侧底部的 V来家连接状态，选择退出当前组织。退出后 V来家查询和定时任务暂停，等待下次登录；普通 AI、文件和本地功能继续可用。退出不会删除 Visionox-Whale 的会话、任务或本地文档。

## 常见问题

### 模型说「DWS 只支持只读查询」

这是旧版能力描述。当前版本既支持查询，也支持受控的消息发送和其他写操作；消息采用智能确认，其他企业写操作保持逐次确认。新建对话后重试，并明确说出目标和操作。

### 模型找不到某个较新的 V来家功能

让模型「先查看当前 DWS 帮助和内置文档，再执行这个需求」。系统可以在运行时发现当前 DWS 支持的命令，不依赖开发电脑目录。

### 登录后仍显示未连接

先等待几秒让状态自动刷新。如果仍未更新，点击「我已完成授权」立即检查；确认授权使用的是当前 Windows 用户，并检查企业网络是否可访问 V来家。

### 默认浏览器没有打开

点击「复制链接」，粘贴到其他可用浏览器完成授权；也可以在尝试默认浏览器后选择「使用 Edge 打开」。浏览器是否成功出现不会中断登录等待，完成授权后回到软件即可。

### 未登录时定时任务怎么办

任务不会弹出登录页面，也不会失败后反复打扰。它会进入「等待登录」状态，完成登录后自动补跑。
