# Visionox 记忆功能使用说明

> 适用版本：Visionox Desktop ≥ 1.0.0

Visionox 提供三层记忆体系，让 AI 助手记住你的偏好、项目事实和临时上下文。记忆按照范围和生命周期分层，不同工作模式下的记忆互不干扰。

---

## 一、快速概览

| 记忆类型 | 什么时候用 | 说一句话就能存 |
|----------|-----------|---------------|
| **会话记忆** | 临时记住当前讨论的上下文 | "记住我们正在分析 Bug #42" |
| **模式偏好记忆** | 让当前模式记住你的工作习惯 | "在编程场景下记住我用 Vite 构建" |
| **全局记忆** | 让 AI 始终记住你的身份/偏好 | "记住我叫张三" |
| **项目记忆** | 让 AI 记住当前项目的关键信息 | "记住这个项目用 Rust + Tauri" |

> **规则一**：同一件事不要用不同的记忆方式重复存，选一个最合适的即可。
> **规则二**：如果只说"记住"，AI 会自动判断该存到哪里。

---

## 二、三种工作场景与记忆切换

### 2.1 切换工作模式

Visionox 有四种内置工作模式，每种模式自动加载对应的提示词和技能：

| 模式 | ID | 适合做什么 |
|------|-----|-----------|
| 通用 | `general` | 日常问答、资料梳理、轻量排查 |
| 编程 | `coding` | 代码阅读、修复、重构、测试、构建 |
| 办公 | `office` | 文档、表格、PDF、PPT、格式转换 |
| 设计 | `design` | 界面体验、前端布局、视觉风格 |

**切换方式**：在设置页的"工作场景"下拉框中选择，或通过 / 命令切换。切换后需要输入 `/new` 或重启对话生效。

### 2.2 模式偏好记忆的隔离规则

> 在编程模式记住的快捷操作，不会跑到办公模式去；反之亦然。

每个模式有自己的记忆库，存在 `~/.visionox/mode-memory/` 目录下，互不干扰：

```
~/.visionox/mode-memory/
├── general.json       # 通用模式记忆
├── coding.json        # 编程模式记忆
├── office.json        # 办公模式记忆
└── design.json        # 设计模式记忆
```

切换到某模式后，该模式的记忆会自动注入到 AI 的提示词中，但最多只取最重要的 8 条，不会让提示词变得臃肿。

## 三、具体使用场景与示例

### 3.1 会话记忆 — 当前对话有效

**适用场景**：临时讨论的上下文、还没确定要不要长期记住的信息。

```
你：记住我们当前分析的 Bug 是 SQLite WAL 模式下的并发写入问题
AI：已记住，在当前对话中生效

你：我们刚才的结论是什么？
AI：根据刚才的记忆，Bug 是 SQLite WAL 模式下的并发写入问题…
```

> 会话记忆在输入 `/new` 或关闭窗口后自动清除，不需要手动删除。

### 3.2 模式偏好记忆 — 让当前模式记住工作习惯

**适用场景**：在某类工作中反复用到的知识点、术语、快捷方式，只想让对应模式记住。

```
你（在编程模式下）：在编程场景下记住 8K 点屏通过 USB ADB 连接
AI：已记住，只影响编程模式

你（切换到办公模式后）：8K 点屏怎么连？
AI：抱歉，我没有这方面的记忆（办公模式没有这条记忆）
```

```
你（在编程模式下）：编程场景下记住我习惯用 Vite + pnpm 构建项目
AI：已保存到编程模式偏好记忆
```

**优先级设置**：可以在记忆时指定优先程度。

```
你：记住调试时优先检查 RUST_LOG 环境变量，这个很重要
AI：已保存（优先级较高，会优先注入到提示词中）
```

### 3.3 全局记忆 — 让 AI 始终记得你

**适用场景**：你的名字、语言偏好、跨项目的通用偏好。

```
你：记住我叫李工，用英文技术术语交流
AI：已记住（跨所有对话和项目生效）
```

```
你：记住我默认使用 VS Code 作为编辑器
AI：已记住
```

### 3.4 项目记忆 — 让 AI 记住当前项目背景

**适用场景**：当前项目的技术栈、约定、关键决策。

```
你：记住这个项目用 Rust + Tauri 2.0，测试框架用 cargo test
AI：已保存到项目记忆
```

```
你：记住项目编码规范要求 unsafe 块必须有 SAFETY 注释
AI：已保存到项目记忆
```

## 四、记忆管理

### 4.1 查看已记住的内容

AI 启动时会在对话开头列出所有已注入的记忆摘要（每条一行）。如果某条记忆的摘要不够详细，可以要求：

```
你：查看我关于编辑器偏好的完整记忆
```

### 4.2 删除记忆

```
你：忘记我刚才说的编辑器偏好
AI：已删除
```

### 4.3 批量清理 — 项目记忆清除

```
你：清除所有项目记忆
```

### 4.4 如果 AI 记错了

```
你：之前说的打包工具不是 webpack，是 vite，更新一下
AI：已更新
```

## 五、记忆优先级说明

AI 在构建提示词时按以下优先级注入记忆：

1. **高优先级**（`priority: high`）→ 作为硬约束注入，最优先遵守
2. **模式偏好记忆** → 按优先级排序，取前 8 条
3. **全局记忆** → 全部加载到提示词
4. **项目记忆** → 全部加载到提示词
5. **会话记忆** → 追加在末尾

> 默认情况下，明确说"这个很重要"的记忆会被标记为较高优先级。

## 六、存储位置（仅供参考，无需手动操作）

| 记忆类型 | 存储位置 |
|----------|----------|
| 会话记忆 | 进程内存，不落盘 |
| 模式偏好记忆 | `~/.visionox/mode-memory/{模式名}.json` |
| 全局记忆 | `~/.visionox/memory/global/*.md` |
| 项目记忆 | `~/.visionox/memory/{项目哈希}/*.md` |
| 项目文件记忆 | 项目目录下的 `REASONIX.md` / `visionox.md` / `AGENTS.md` 等 |

> 不建议直接在文件系统中增删改，通过对话操作即可。

## 七、常见问题

**Q：我在编程模式记住的内容，切换到通用模式还能用吗？**
A：不能。模式偏好记忆是按模式隔离的。如果某条记忆应该在所有模式都生效，请使用全局记忆（`remember`）而不是模式偏好记忆。

**Q：记忆内容有长度限制吗？**
A：单条模式偏好记忆建议不超过 180 个字符，太长的内容会被自动截断。全局和项目记忆的单条上限是 8000 字符。

**Q：怎么知道当前是什么模式？**
A：对话开始时 AI 会显示"当前工作模式"信息和已加载的模式记忆。也可以在设置页查看。

**Q：模式偏好记忆最多能存多少条？**
A：每个模式最多 60 条，但注入提示词时最多只取 8 条（按优先级排序）。旧的、低优先级的条目不会丢失，但不会自动注入——除非提升其优先级。

**Q：如何完全关闭记忆功能？**
A：设置环境变量 `VISIONOX_MEMORY=off`（旧版本也兼容 `REASONIX_MEMORY=off`）可禁用所有记忆注入。
