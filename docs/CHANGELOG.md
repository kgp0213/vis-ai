# Visionox 更新日志

> 本文档记录 Visionox-Whale 及此前 Visionox Desktop 各版本面向用户的功能变更。

---

## v1.28.0

### 产品与发布

- 产品名称统一为 Visionox-Whale，可执行文件更名为 `visionox-whale.exe`。
- 保留 `com.visionox.desktop` 与 `%USERPROFILE%\.visionox\`，兼容已有会话、设置、记忆和任务数据。
- release 与 NSIS 构建改为离线、单一资源源和逐文件 SHA256 完整性校验。
- NSIS 安装包名称调整为 `Visionox-Whale_1.28.0_x64-setup.exe`。
- 根包、Cargo 与 Tauri 版本在提交和构建前强制一致；release 构建契约覆盖离线环境、唯一目标和临时目录清理。

### 对话、索引与知识整理

- 千条以上长会话改为分页和窗口化渲染，恢复历史时不再让输入框随整段记录重渲染。
- 聊天输入区提供“自动召回 / 按需搜索 / 不使用”三种会话级索引模式，并在新建会话和切换工作场景时保留选择。
- 语义索引纳入工作区 `knowledge/` 文档，召回结果区分工作区与知识来源，并按来源保留配额。
- 会话整理任务增加 AI 质量评估、低价值过滤、跨会话同主题合并、详细知识文档生成和可选自动 embedding 更新。
- 知识文档固定归档到工作区 `knowledge/`，不再写入 `.visionox/knowledge`。

### 模型、会话与界面

- JSON 导入后将全部模型标记为待检测；模型检测覆盖所有已保存服务商，10 秒超时，只为通信通过的模型显示对号。
- 检测成功后自动启用第一个可用模型，同时保留外部 DeepSeek `auto / flash / pro` 与内部单模型的既有切换规则。
- 会话页增加批量移入回收站、回收站预览与恢复、保留期配置和自动过期清理。
- 概览整合高价值系统状态，并提供用户数据容量、备份时间和损坏快照提示。

### 记忆与可靠性

- 记忆管理区分磁盘已保存与当前上下文已生效状态，并支持空闲时立即应用。
- 场景记忆支持保留状态的原子移动、复制和批量管理，超长内容不再静默截断。
- Soul 提供基础编辑、高级原文、最终注入预览、默认恢复和最近版本恢复。
- 长期记忆增加并发版本校验、正文搜索和可恢复删除；项目规则显示实际预算与截断状态。
- 项目根目录的 `AGENTS.md`、`AGENT.md`、`agent.md`、`CLAUDE.md`、`claude.md` 与 `visionox.md` 可作为项目记忆，明确排除 `REASONIX.md`。
- 定时任务、Skill 替换和活动计划采用校验后提交、原子写入与失败回滚，损坏或更高版本数据不再被静默覆盖。
- 用户数据支持带 SHA-256 清单的完整快照、恢复预览和默认不覆盖冲突的恢复；向量索引、日志与缓存不进入快照。
- 快照支持创建前容量估算、显式删除和 1–100 份保留策略；自动裁剪只在成功创建或保存策略后发生。
- 模式记忆、提示队列、知识清单和会话元数据拒绝覆盖损坏或更高版本 JSON，并在概览显示存储保护状态。
- 核心运行时模块执行 90% 行、60% 分支、90% 函数的最低覆盖率门禁。

### 开发与维护

- 内置 OfficeCLI 从 1.0.129 更新到 1.0.135，纳入 Excel 查询、公式/图表、批处理以及 Word/PPT 选择器和预览修复。
- 保留先准备运行资源的 `tauri:dev` 用于快速 UI 调试，同时强制 release 交付构建使用规范 wrapper。
- 核心 API 响应增加 JSON Schema 契约检查，聚合测试文件增加体积上限，新行为按领域拆分测试。
- Rust 工具链固定为 1.94.0，CI 同时检查暂存和未暂存差异中的空白问题。
- Node、OfficeCLI、Reasonix、KaTeX 和 bootstrap skills 增加随包分发的机器可读来源、版本、许可证与哈希清单。
- 运行时问题按 debug/warning/error/fatal 分级；概览仅显示需要用户处理的 warning/error。
- 提示队列存储从 Launcher 抽取为独立模块；Dashboard 备份策略成为首个可读、独立测试的迁移模块。
- Active session metadata 抽取为版本化存储模块，损坏或高版本文件经过真实文件测试确认不会被覆盖。
- 活动会话正文写盘失败进入概览存储告警；多模态消息兜底同步避免重复用户消息并保留图片元数据。
- Soul、工程规则、模式记忆回滚、知识主题读取和活动计划清理不再静默失败；知识主题不可读时禁止覆盖。
- Dashboard 索引模式归一化与提示抽取为第二个可读策略模块，异常值安全回退到按需搜索。
- 概览告警判定抽取为可独立测试的纯策略模块，锁定告警顺序、严重级别、索引条件和预算边界。
- 41 个 bootstrap skills 全部进入 provenance 清单；当前 7 项来源和许可证已核验，34 项明确标记待补证。
- 定时任务运行登记、取消、并发限制、补跑和忙碌延迟决策从 Launcher 抽取为独立执行编排模块。
- 重启遗留运行记录通过真实定时任务存储测试恢复为失败；运行状态写盘失败会进入用户数据告警并停止未启动任务。

## v1.11.0

### 报告生成优化

- 报告标题格式改为「{日期} Visionox {日报/周报}」（如 `2026-07-03 Visionox 日报`）
- 报告提示词拆分为**默认提示词**（随版本更新）+ **用户追加指令**（跨升级保留），解决升级覆盖问题
- 首次生成报告时自动迁移旧版自定义提示词为追加指令（LLM 辅助提取差异）
- 报告严格基于历史会话记录生成，不主动读取工作区文件；信息缺失时如实说明而非编造
- 前端「报告提示词」编辑器拆分为只读默认区 + 可编辑追加区
- 报告生成排除 `.events.jsonl` 噪声文件，预览→生成增加 30s 缓存消除双读
- `/report` 斜杠命令改为调用异步报告引擎，不再阻塞事件循环

### 8 层记忆系统修复

- **L1 项目记忆注入修复**：`buildLoop` 现在正确调用 `applyProjectMemory`，项目根目录中的 Agent、Claude 和 `visionox.md` 规则文件会在新对话中自动注入（此前因未导入该函数而缺失）
- **L6/L7 注入顺序统一**：技能索引（L6）现在在持久记忆（L7）之前注入，与文档描述一致
- README 8 层描述补充 L8 会话记忆

### 工作模式即时切换

- Dashboard 切换工作模式后**立即重建 loop**，下一条消息即生效（此前需 `/new` 才刷新，且 `/status` 会谎报新模式）
- 技能索引按当前模式标注 ⭐ 推荐技能，消除「Relevant skills」提示与技能目录的矛盾信号
- Work mode 块增加护栏声明：模式提示与 soul 身份冲突时以 soul 为准

### 性能优化（第一梯队）

- **config 读取缓存**：`readConfig` 增加 mtime 缓存，消除每次工具调用权限检查的同步读盘（`loadEditMode`/`loadProjectShellAllowed` 等），单 turn 减少 10+ 次 `readFileSync`+`JSON.parse`
- **buildLoop 前缀记忆化**：系统提示词静态前缀按源文件 mtime 指纹缓存，`/new`、切模式、旁路问句等 11 个调用点命中缓存时跳过 `loadRules`/`applySkillsIndex`/`loadSoul` 等全部磁盘读取
- **bootstrap 技能 hash 优化**：启动时通过 marker 中的 `sourceMtime` 跳过未变更技能源目录的全量 hash，稳态启动零文件读取（此前每次启动读 58 个文件）
- **active-session 持久流**：会话自动保存改用持久 `WriteStream` 替代每条消息 `appendFile`（open/write/close 三连），user 消息不再被磁盘 I/O 阻塞

### 性能优化（第二梯队）

- **升级首字延迟优化**：`autoEscalate` 的标记检测缓冲从 256 字符改为首行检测（检测到换行即 flush），常见路径首字延迟从「最多 256 字符」降到「最多一行」，检测语义不变
- `NEEDS_PRO_BUFFER_CHARS` 支持环境变量 `visionox_NEEDS_PRO_BUFFER_CHARS` 覆盖
- 升级时被丢弃的 flash 请求 token 成本现在计入统计（此前 `usage=null` 完全隐藏）
- **session memory 子预算**：每条 body 上限 2000 字符，集体块上限 6000 字符（超限丢最旧整条），防止模型写入的临时记忆膨胀提示词
- **rules 子预算**：编码规则集体上限 12000 字符（超限从 custom 起尾弃整条），防止 coding 模式加载 ~100KB 规则

### `/learn` 学习命令

新增统一学习命令，在对话中把项目知识转化为 AI 可复用的长期能力：

| 命令 | 说明 |
|------|------|
| `/learn skill <目录>` | 扫描目录，调用 LLM 生成 SKILL.md 并安装 |
| `/learn project` | 扫描 workspace，更新项目记忆文件 |
| `/learn index <目录>` | 为目录构建语义索引 |
| `/learn ask <问题>` | 基于语义索引问答 |
| `/learn tutor` | 导师模式（苏格拉底/提示/结对/关闭） |
| `/learn track` | 概念库 + SM-2 间隔重复学习追踪 |

## v1.10.0（2026-06-26）

### 模型配置 JSON 导入

对话框底部「🤖 模型」面板支持 JSON 文件批量导入/更新 Provider 配置，方便多设备间同步。

### 剪贴板粘贴增强

- `Ctrl+V` 粘贴图片/截图自动添加为附件
- `Ctrl+V` 粘贴文件/文件夹自动贴入完整本地路径
- 支持更多 Windows 剪贴板格式，OneDrive/Outlook/远程桌面等复杂场景成功率更高

### Superpowers 技能包内置

安装包自带 14 个 Superpowers 工作流技能（需求梳理、方案规划、TDD、系统调试等），安装后自动可用。

### WebView2 刷新修复

修复 iframe 方案下 F5/右键刷新卡死问题，三层恢复机制确保刷新后自动重建 dashboard。

### OfficeCLI 正式内置

`officecli.exe` 纳入安装包，启动时自动注入 MCP，办公模式开箱即用。
