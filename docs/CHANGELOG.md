# Visionox 更新日志

> 本文档记录 Visionox-Whale 及此前 Visionox Desktop 各版本面向用户的功能变更。

---

## v1.28.1（开发中）

### 架构

- **回退通用复杂任务状态机**：移除 `foreground-task-supervisor.mjs` 及前台监督接线，模型工具循环（`CacheFirstLoop`）重新成为唯一执行内核。多步骤任务通过轻量 `submit_plan` / `mark_step_complete` / `todo_write` 处理，不再维护独立的任务状态机、步骤调度器或完成守卫。约 40 个 `complex-task-*.mjs` 历史文件已归档到 `legacy/complex-task/`，不再进入运行时或默认测试。
- **上下文输入缓存跨回合保留**：`context-input-transaction.mjs` 状态主键从 `turnId` 改为 `transactionId`，用户插话或切换工具不再丢失已缓存的大段工具结果引用。
- **二进制文件不再误读为文本**：`read_file` 经 DLP 包装层嗅探文件 magic number（PDF / Office 容器 / 图片等），命中二进制类型时直接拒绝并引导改用 `prepare_local_document`，避免二进制内容污染上下文。
- **工具退出码判定修正**：`toolResultSucceeded` 正则去掉末尾锚定，正确识别 `run_command` 输出中位于中间位置的 `[exit N]` 标记，失败命令不再被误计为成功。
- **plan 模式放行文档准备**：`prepare_local_document` 标记为只读工具，可在 plan 阶段执行，模型不再需要绕道 `read_file` 直接读 PDF。

## v1.28.0

### 普通用户最值得更新的变化

- **长对话更流畅**：打开上千条消息的历史会话时，只加载当前需要查看的内容，输入、滚动和切换更轻快。
- **模型配置更省心**：导入 JSON 后可以一次检测全部模型；可用模型会显示对号，并自动启用第一个检测成功的模型。
- **切换项目不串内容**：工作区、项目记忆、技能和本地索引彼此隔离；定时任务也会按用户选择的工作区规则继续执行。
- **定时报告不会再找不到**：报告始终保存在任务记录中，可直接预览；是否另外导出到下载目录由用户决定。
- **误删内容更容易找回**：会话和记忆都提供回收站、内容预览和恢复，用户数据还可以创建完整快照。
- **常用能力随安装包提供**：OfficeCLI、KaTeX、Tavily 搜索和常用技能随软件安装，不需要用户自行配置运行环境。
- **受保护文档连续处理**：文档准备后使用稳定引用连接原始文件与明文副本；切换 Skill、恢复会话或临时副本缺失时可自动重新准备，不再依赖模型记住临时路径。
- **PDF 读取不再依赖 Python**：内置 PDF.js 负责现有 PDF 文本提取，OfficeCLI 只处理 Word/Excel/PPT；Markdown 转 PDF Skill 不再被误用为读取器。
- **大型文档整理可恢复**：PDF、Word、Excel、PPT、HTML、Markdown、CSV 和文本统一通过后台任务生成“独立摘要 + 完整正文”，支持进度、暂停、继续、取消、预览和失败块重试；Qwen 超时只影响当前区块，并可由健康备用模型接管。
- **异机中断可以续接**：Windows 安全软件占用任务文件时自动重试，持续禁止覆盖时改用有界版本快照；进度保存失败不再终止本地服务，已生成区块通过独立检查点恢复，最终取消也会保留此前中断记录。
- **跨页内容不再被机械切断**：页面仍用于完整性追踪，但模型按语义窗口理解跨页句子、续表和连续步骤；相邻页只作为上下文，最终正文会再次检查缺页、重复和顺序错误。
- **图表不再静默丢失**：配置多模态模型时按需渲染 PDF 页面、Office 元素和本地 HTML 图片进行分析；没有可用视觉模型时保留位置并标记复核，不再虚报完整。
- **V来家协作互通**：内置 DWS 后可查询企业钉钉消息、通讯录、日程、待办、审批和文档；左侧提供不阻塞 AI 的 Device Flow 登录/退出入口，连通时显示当前用户名。安全消息可按当前请求或用户保存的定时任务直接发送，高风险和不确定内容仍需确认。
- **V来家登录更容易排查**：登录失败会区分网络/代理、证书、权限、组件版本和超时，并在卡片中给出可操作提示；本机日志同步记录 DWS 路径、原始 stdout/stderr、退出码和失败原因，异机问题不再只能看到“授权未完成”。
- **V来家定时整理**：普通任务可选择每日简报、待回应雷达、会议行动项、每周总结、专题调查和日志一致性核查；未登录时等待而不打断 AI，登录后补跑。
- **V来家报告与知识归档**：成功结果保存为可预览 Markdown；用户可绑定固定工作区，经 AI 质量审核后手动或自动归档到 `knowledge/vhome/`，并独立控制是否更新索引。
- **DWS 分层适配器**：只读查询统一响应差异、超时、分页和输出上限；消息发送由宿主独立判断风险，未来业务命令可经确认调用完整 DWS 接口，全部使用随包运行时路径。
- **对话式 V来家 Skill 创建**：明确提出创建或定制需求时，通过交互卡片补齐信息，先校验和只读 mock，再经最终确认原子安装；普通查询和技术讨论不会误触发。

### 产品与发布

- 产品名称统一为 Visionox-Whale，可执行文件更名为 `visionox-whale.exe`。
- 保留 `com.visionox.desktop` 与 `%USERPROFILE%\.visionox\`，兼容已有会话、设置、记忆和任务数据。
- release 与 NSIS 构建改为离线、单一资源源和逐文件 SHA256 完整性校验。
- NSIS 安装包名称调整为 `Visionox-Whale_1.28.0_x64-setup.exe`。
- 根包、Cargo 与 Tauri 版本在提交和构建前强制一致；release 构建契约覆盖离线环境、唯一目标和临时目录清理。

### 对话、索引与知识整理

- 千条以上长会话改为分页和窗口化渲染，恢复历史时不再让输入框随整段记录重渲染。
- 聊天输入区提供“自动召回 / 按需搜索 / 不使用”三种会话级索引模式，并在新建会话和切换工作场景时保留选择。
- 语义索引纳入工作区 `knowledge/` 文档，召回结果区分工作区与知识来源，并按来源保留配额。
- 会话整理任务增加 AI 质量评估、低价值过滤、跨会话同主题合并、详细知识文档生成和可选自动 embedding 更新。
- 知识文档固定归档到工作区 `knowledge/`，不再写入 `.visionox/knowledge`。

### 模型、会话与界面

- JSON 导入后将全部模型标记为待检测；模型检测覆盖所有已保存服务商，10 秒超时，只为通信通过的模型显示对号。
- 公司模型支持 `requestPolicy: "json"`，请求参数、思考开关和采样设置完全由导入 JSON 决定；可选的 `verificationRequestDefaults` 只在 10 秒通信检测时递归覆盖正式参数，避免检测简单连通性时触发耗时思考。
- Qwen 等 OpenAI `/chat/completions` 兼容模型可直接通过 JSON 增减原生参数；程序不硬编码模型厂商的推理档位映射，模型升级通常不需要重新构建软件。
- 模型配置新增 schema v3 维护包，可按稳定模型 `key` 执行新增、改名、API ID 升级、同步停用和显式删除；导入前展示后端计算的真实变更，危险删除需单独确认。
- 设置页可选择任意服务商轮换 API Key 或 Base URL；新配置必须先通过 10 秒通信检测才能保存，检测失败不会覆盖现有可用凭据。
- 检测成功后自动启用第一个可用模型，同时保留外部 DeepSeek `auto / flash / pro` 与内部单模型的既有切换规则。
- 会话页增加批量移入回收站、回收站预览与恢复、保留期配置和自动过期清理。
- 概览整合高价值系统状态，并提供用户数据容量、备份时间和损坏快照提示。

### 记忆与可靠性

- 桌面加载页等待 Dashboard 完成首次渲染并发送 ready 握手后才显示界面；超时进入可操作的日志诊断页，避免慢电脑出现空白窗口。
- 主动退出会先标记宿主关闭状态，Node 崩溃监控不会在退出过程中重新启动本地服务。
- OfficeCLI MCP 单次长操作超时由默认 60 秒放宽到 180 秒，其他 MCP 保持默认超时，超时恢复机制继续保留。
- 纯文本 Windows 文件或目录路径粘贴直接在输入框本地完成，不再先启动 PowerShell；资源管理器复制文件时优先使用 Rust 原生剪贴板桥。
- 记忆管理区分磁盘已保存与当前上下文已生效状态，并支持空闲时立即应用。
- 场景记忆支持保留状态的原子移动、复制和批量管理，超长内容不再静默截断。
- Soul 提供基础编辑、高级原文、最终注入预览、默认恢复和最近版本恢复。
- 长期记忆增加并发版本校验、正文搜索和可恢复删除；项目规则显示实际预算与截断状态。
- 项目根目录的 `AGENTS.md`、`AGENT.md`、`agent.md`、`CLAUDE.md`、`claude.md` 与 `visionox.md` 可作为项目记忆，明确排除 `REASONIX.md`。
- 定时任务、Skill 替换和活动计划采用校验后提交、原子写入与失败回滚，损坏或更高版本数据不再被静默覆盖。
- 多个定时任务同时触发时改为单槽 FIFO 排队，同一任务重复触发自动合并；前一任务完成、取消或主对话空闲后立即续跑，重启补跑仍按原触发时间排序。
- 用户数据支持带 SHA-256 清单的完整快照、恢复预览和默认不覆盖冲突的恢复；向量索引、日志与缓存不进入快照。
- 快照支持创建前容量估算、显式删除和 1–100 份保留策略；自动裁剪只在成功创建或保存策略后发生。
- 模式记忆、提示队列、知识清单和会话元数据拒绝覆盖损坏或更高版本 JSON，并在概览显示存储保护状态。
- 核心运行时模块执行 90% 行、60% 分支、90% 函数的最低覆盖率门禁。

## v1.11.0

### 报告生成优化

- 报告标题格式改为「{日期} Visionox {日报/周报}」（如 `2026-07-03 Visionox 日报`）
- 报告提示词拆分为**默认提示词**（随版本更新）+ **用户追加指令**（跨升级保留），解决升级覆盖问题
- 首次生成报告时自动迁移旧版自定义提示词为追加指令（LLM 辅助提取差异）
- 报告严格基于历史会话记录生成，不主动读取工作区文件；信息缺失时如实说明而非编造
- 前端「报告提示词」编辑器拆分为只读默认区 + 可编辑追加区
- 报告生成排除 `.events.jsonl` 噪声文件，预览→生成增加 30s 缓存消除双读
- `/report` 斜杠命令改为调用异步报告引擎，不再阻塞事件循环

### 8 层记忆系统修复

- **L1 项目记忆注入修复**：`buildLoop` 现在正确调用 `applyProjectMemory`，项目根目录中的 Agent、Claude 和 `visionox.md` 规则文件会在新对话中自动注入（此前因未导入该函数而缺失）
- **L6/L7 注入顺序统一**：技能索引（L6）现在在持久记忆（L7）之前注入，与文档描述一致
- README 8 层描述补充 L8 会话记忆

### 工作模式即时切换

- Dashboard 切换工作模式后**立即重建 loop**，下一条消息即生效（此前需 `/new` 才刷新，且 `/status` 会谎报新模式）
- 技能索引按当前模式标注 ⭐ 推荐技能，消除「Relevant skills」提示与技能目录的矛盾信号
- Work mode 块增加护栏声明：模式提示与 soul 身份冲突时以 soul 为准

### 性能优化（第一梯队）

- **config 读取缓存**：`readConfig` 增加 mtime 缓存，消除每次工具调用权限检查的同步读盘（`loadEditMode`/`loadProjectShellAllowed` 等），单 turn 减少 10+ 次 `readFileSync`+`JSON.parse`
- **buildLoop 前缀记忆化**：系统提示词静态前缀按源文件 mtime 指纹缓存，`/new`、切模式、旁路问句等 11 个调用点命中缓存时跳过 `loadRules`/`applySkillsIndex`/`loadSoul` 等全部磁盘读取
- **bootstrap 技能 hash 优化**：启动时通过 marker 中的 `sourceMtime` 跳过未变更技能源目录的全量 hash，稳态启动零文件读取（此前每次启动读 58 个文件）
- **active-session 持久流**：会话自动保存改用持久 `WriteStream` 替代每条消息 `appendFile`（open/write/close 三连），user 消息不再被磁盘 I/O 阻塞

### 性能优化（第二梯队）

- **升级首字延迟优化**：`autoEscalate` 的标记检测缓冲从 256 字符改为首行检测（检测到换行即 flush），常见路径首字延迟从「最多 256 字符」降到「最多一行」，检测语义不变
- `NEEDS_PRO_BUFFER_CHARS` 支持环境变量 `visionox_NEEDS_PRO_BUFFER_CHARS` 覆盖
- 升级时被丢弃的 flash 请求 token 成本现在计入统计（此前 `usage=null` 完全隐藏）
- **session memory 子预算**：每条 body 上限 2000 字符，集体块上限 6000 字符（超限丢最旧整条），防止模型写入的临时记忆膨胀提示词
- **rules 子预算**：编码规则集体上限 12000 字符（超限从 custom 起尾弃整条），防止 coding 模式加载 ~100KB 规则

### `/learn` 学习命令

新增统一学习命令，在对话中把项目知识转化为 AI 可复用的长期能力：

| 命令 | 说明 |
|------|------|
| `/learn skill <目录>` | 扫描目录，调用 LLM 生成 SKILL.md 并安装 |
| `/learn project` | 扫描 workspace，更新项目记忆文件 |
| `/learn index <目录>` | 为目录构建语义索引 |
| `/learn ask <问题>` | 基于语义索引问答 |
| `/learn tutor` | 导师模式（苏格拉底/提示/结对/关闭） |
| `/learn track` | 概念库 + SM-2 间隔重复学习追踪 |
