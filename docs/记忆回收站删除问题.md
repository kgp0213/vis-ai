# 记忆回收站无法彻底删除问题

> 审查日期：2026-07-12
> 问题：记忆管理页面的回收站只能恢复，不能彻底删除，文件永久堆积

---

## 一、问题确认

记忆删除时软删除到 `~/.visionox/memory-trash/` 目录（单个 JSON 文件），但回收站只有"恢复此记忆"按钮，没有"永久删除"或"清空回收站"功能。文件永久堆积，唯一的移除方式是恢复（消费掉 trash 条目）或手动到磁盘删除 JSON 文件。

### 对比：会话回收站功能完整

| 功能 | 会话回收站 | 记忆回收站 |
|------|-----------|-----------|
| 恢复 | ✅ | ✅ |
| 永久删除单条 | ✅ `DELETE /sessions/trash/batch` | ❌ 返回 400 |
| 清空回收站 | ✅ | ❌ |
| 自动过期清理 | ✅ 30 天 + 定时 prune | ❌ 无 |
| 前端删除按钮 | ✅ | ❌ 显式隐藏 |

### 根因链路

```
前端 MemoryPanel (app.js)
  └─ trash 项只渲染"恢复"按钮 (L28713)
  └─ "删除"按钮对 trash 显式隐藏 (L28714: open.kind !== "trash")
  └─ 无"清空回收站"按钮

后端 handleMemory (server-XGDBRWMB.js)
  └─ DELETE 分支 (L2010-2047)
     ├─ scope=session -> 直接删除 ✅
     ├─ scope=global/project-mem -> 软删除到 trash ✅
     ├─ scope=project -> 直接删除 ✅
     └─ scope=trash -> return 400 "bad scope or name" ❌

Launcher (launcher.mjs)
  └─ 无 deleteMemoryTrash / purgeMemoryTrash 函数
  └─ 无自动过期清理（会话有 pruneExpiredSessionTrash，记忆没有）
```

---

## 二、解决方案

需要补三层：后端 API + launcher 函数 + 前端按钮。可选第四层：自动过期清理。

### 2.1 后端：handleMemory DELETE 分支添加 trash 支持

在 `server-XGDBRWMB.js` handleMemory 的 DELETE 分支中，为 `scope === "trash"` 添加处理：

```js
// 在 scope=project 分支之后、fallback return 400 之前添加：
if (scope === "trash") {
  const trashDir = memoryTrashDir(memoryHomeDir);
  const target = join(trashDir, `${name}.json`);
  // 安全校验：路径必须在 trashDir 内
  const resolved = resolve(target);
  if (!resolved.startsWith(trashDir + sep)) {
    return { status: 403, body: { error: "invalid trash path" } };
  }
  if (!existsSync(target)) {
    return { status: 404, body: { error: "trash item not found" } };
  }
  unlinkSync(target);
  return { status: 200, body: { deleted: true } };
}
```

可选：额外加 `POST /memory/trash/empty` 路由支持批量清空。

### 2.2 Launcher：导出删除函数

在 `launcher.mjs` 中添加（类比会话的 `deleteSessionTrash`）：

```js
function deleteMemoryTrash(ids) {
  const dir = resolve(visionoxDataDir, "memory-trash");
  let deleted = 0, failed = 0;
  for (const id of ids) {
    try {
      const target = resolve(dir, `${id}.json`);
      if (target.startsWith(dir + sep) && existsSync(target)) {
        unlinkSync(target);
        deleted++;
      }
    } catch { failed++; }
  }
  return { deleted, failed };
}

function purgeMemoryTrash() {
  const dir = resolve(visionoxDataDir, "memory-trash");
  let deleted = 0;
  try {
    for (const f of readdirSync(dir).filter(f => f.endsWith(".json"))) {
      unlinkSync(resolve(dir, f));
      deleted++;
    }
  } catch {}
  return { deleted };
}
```

然后在 ctx 对象中导出：`deleteMemoryTrash`、`purgeMemoryTrash`。

### 2.3 前端：MemoryPanel 添加删除按钮

在 `app.js` MemoryPanel 的 trash 项操作区，"恢复此记忆"按钮旁边添加"永久删除"按钮：

```js
${open.kind === "trash" ? html4`
  <button class="btn primary" disabled=${busy} onClick=${restoreTrash}>恢复此记忆</button>
  <button class="btn danger" disabled=${busy} onClick=${() => {
    if (confirm("永久删除此记忆？此操作不可撤销。")) permanentlyDeleteTrash(open.name);
  }}>永久删除</button>
` : ...}
```

`permanentlyDeleteTrash` 函数调用 `DELETE /memory/trash/${name}`，成功后 reload。

可选：在回收站 scope 顶部加"清空回收站"按钮，调用 `POST /memory/trash/empty`。

### 2.4 可选：自动过期清理

类比会话回收站的 30 天自动清理：

```js
const DEFAULT_MEMORY_TRASH_RETENTION_DAYS = 30;

function pruneExpiredMemoryTrash() {
  const dir = resolve(visionoxDataDir, "memory-trash");
  if (!existsSync(dir)) return;
  const cutoff = Date.now() - DEFAULT_MEMORY_TRASH_RETENTION_DAYS * 86400000;
  for (const f of readdirSync(dir).filter(f => f.endsWith(".json"))) {
    try {
      const stat = statSync(resolve(dir, f));
      if (stat.mtimeMs < cutoff) unlinkSync(resolve(dir, f));
    } catch {}
  }
}
```

在启动时调用一次 + `setInterval` 每小时调用一次（与会话回收站一致）。
