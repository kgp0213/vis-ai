# 提示词优化功能使用说明

## 这是什么

输入框旁边有一个「优化提示词」按钮。写完一句话后点一下，AI 会帮你把话说得更清楚、更具体，让回答更精准。

## 怎么用

1. 在输入框里写下你的需求（比如"帮我写个周报"）
2. 点旁边的「优化提示词」按钮
3. 等几秒，输入框里的内容会被替换成优化后的版本
4. 看一眼，觉得没问题就点发送

## 三个要点

- **不会自动发送**：优化后内容只是填回输入框，你看完确认了再发送
- **可以再改**：优化后的内容你还能手动编辑，不是最终版
- **改了就不覆盖**：如果优化过程中你又改了输入框，不会覆盖你的修改

## 什么时候用

| 你的情况 | 用不用 |
|---|---|
| 写得很短，怕 AI 理解不准 | 用，AI 会帮你补充细节 |
| 不确定怎么描述需求 | 用，AI 会帮你组织语言 |
| 已经写得很详细了 | 不用，直接发送就行 |
