# 提示词优化功能使用说明

## 这是什么

输入框旁边有一个「优化提示词」按钮。它只改写当前草稿，使任务表达更清楚、更具体；不会回答问题或执行任务。

## 怎么用

1. 在输入框里写下需求（例如“帮我写个周报”）
2. 点旁边的「优化提示词」按钮
3. 等待预览，比较“原文”和“优化稿”
4. 点“应用”才会把优化稿写入输入框；点“保留原文”则不改草稿
5. 应用后仍可点“恢复原文”，确认无误后再自行发送

## 三个要点

- **不会自动发送，也不读取对话上下文**：优化只使用当前输入框的草稿，结果始终需要你确认后自行发送。
- **保留关键内容**：原始意图、语言、事实、文件路径、URL、数字、日期、专有名称、范围、限制和交付要求不能被增删改；系统发现不一致时会保留原文。
- **支持 Skill 前缀**：`@Skill 任务正文` 会保留 `@Skill` 前缀，只优化任务正文。
- **草稿变化优先**：优化期间编辑草稿、切换会话/工作区/模式或开始主任务会取消本次优化，不会覆盖新内容。

## 不能优化的内容

- 空草稿，以及只有 `@Skill` 而没有任务正文的输入。
- 任何以 `/` 开头的斜杠命令，包括未知命令；请直接执行或修改命令。

## 取消与错误

请求进行时可以点“取消”。取消、超时、网络或服务错误都不会修改当前草稿。网络中断后若暂时无法确认服务端请求已经停止，界面会保留草稿并提示“重试清理”；清理成功前不会允许再次发送或优化。鉴权失败应检查模型服务凭据，服务繁忙时稍后重试。

## 什么时候用

| 你的情况 | 用不用 |
|---|---|
| 写得很短，怕 AI 理解不准 | 用，AI 会帮你补充细节 |
| 不确定怎么描述需求 | 用，AI 会帮你组织语言 |
| 已经写得很详细了 | 不用，直接发送就行 |
