# Visionox-Whale 快速上手

> 适合第一次使用 Visionox-Whale 的用户，通常几分钟即可完成首次对话。

## 1. 安装并启动

1. 运行 `Visionox-Whale_1.28.0_x64-setup.exe`。
2. 按安装向导完成安装，然后启动 Visionox-Whale。
3. 首次启动默认使用浅色界面，可在左下角切换其他配色。

升级安装通常会保留已有会话、模型配置、记忆和定时任务。重要数据建议先在“概览”中创建一次用户数据快照。

## 2. 导入并检测模型

1. 点击主界面下方的“模型”。
2. 点击“导入模型配置”，选择管理员或服务提供方给你的 JSON 文件；普通新增和更新会自动完成导入。
3. 如果配置包含永久删除，软件会额外询问一次，确认后才会继续。
4. 导入后点击“检测全部模型”。软件会检测所有已配置模型。
5. 检测成功的模型会显示“可用”，并自动启用第一个可用模型。
6. 如有失败项，可点击“删除检测失败模型”；软件只会删除本轮检测确认不可用的模型。

“未检测”表示尚未通信检测，“不可用”表示本轮检测失败。网络不稳定时建议先重新检测，再决定是否删除；无需反复导入同一个文件。

模型配置可以分别声明正式对话参数和通信检测参数。普通用户不需要理解这些字段，只需使用管理员提供的完整 JSON；模型升级后通常也是更换 JSON，不需要重新安装软件。

以后公司更换 API Key 或接口地址时，进入“高级 → 设置 → 模型服务凭据”，选择对应服务商并填写新值。必须先点击“检测 API”，通过后“保存凭据”才可用；填错时旧配置不会被覆盖。

## 3. 开始第一次对话

在输入框中直接描述目标，然后发送。例如：

- `帮我总结这份会议记录，并列出待办事项。`
- `分析这个 Excel 表中的异常数据。`
- `阅读当前项目，帮我定位启动失败的原因。`

需要新话题时点击新建会话。切换“通用、编程、办公、设计”工作场景不会删除当前内容，只会调整 AI 的处理方式。

## 4. 选择工作区

工作区是 AI 默认读取和保存文件的目录。点击输入框下方的“工作空间”，选择已有目录或浏览其他目录。

- 工作区切换会在新建或恢复会话时生效，不会突然改变正在进行的对话。
- 不同工作区的项目记忆、技能和本地索引彼此隔离。
- 切换工作区不会删除或移动原目录中的文件。

## 5. 选择索引模式

输入框下方的“索引”提供三种选择：

| 模式 | 适合场景 |
|---|---|
| 自动召回 | 希望 AI 每次都主动参考工作区和知识文档 |
| 按需搜索 | 普通对话；需要时再让 AI 搜索本地内容 |
| 不使用 | 当前问题与本地文件无关，或明确不希望参考工作区 |

你的选择会在新建会话和切换工作场景后继续保留。

## 6. 使用文件和常用工具

- Markdown：点击右上角“打开 MD”直接预览。
- Word、Excel、PPT、PDF：把文件路径发给 AI，并说明要完成的操作。
- 网页搜索：首次使用 `@tavily-search` 时按界面提示填写 Tavily API Key。
- V来家：点击左侧底部“登录 V来家”完成授权；连接后显示当前用户名，可直接询问未读消息、日程、通讯录、待办和审批。等待授权时不影响普通 AI 功能。
- 数学公式：聊天、报告和 Markdown 预览支持 KaTeX 公式显示。

Node、OfficeCLI、DWS、KaTeX 和常用技能已经随安装包提供，普通用户不需要另外安装这些运行环境。

## 7. 找回和保护数据

- 删除的会话和记忆会先进入回收站，可预览后恢复。
- 在“概览”中定期创建用户数据快照，尤其建议在升级或批量整理前创建。
- 定时会话报告始终保存在任务记录中，可直接预览；“导出到下载目录”只是额外副本。

更详细的记忆、任务、索引和高级设置说明，请继续阅读[用户指南](USER_GUIDE.md)。
