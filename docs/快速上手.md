# Visionox-Whale 快速上手

> 适用版本：1.28.0 ｜ 适合对象：第一次打开本软件的你
> 全程大约 10 分钟：装完 -> 配好模型 -> 发出第一句话。

欢迎你！👋

不需要任何技术背景，跟着步骤点下去就行。每一步都告诉你"会看到什么""点哪里""出错了怎么办"。

---

## 开始之前：请准备好这三样

| 你需要 | 说明 |
|---|---|
| 💻 一台 Windows 电脑 | 64 位系统。WebView2 组件在 Win10/Win11 上基本已内置 |
| 🔑 模型配置 | 管理员给你的 **JSON 文件**（最省事），或一个 **API Key** |
| 🌐 能联网 | 配置模型和 AI 对话时需要网络；本地文档处理不联网 |

> 没有 JSON 也没有 API Key？先找管理员要一份，这是 AI 能"开口说话"的钥匙。

---

## 第一步：安装并启动（约 2 分钟）

1. 双击运行安装包 **`Visionox-Whale_1.28.0_x64-setup.exe`**
2. 按安装向导一路"下一步"即可
3. 安装完成后启动 **Visionox-Whale**

**你会看到：** 启动画面中央有信号动画和进度条，通常几秒进入主界面。

> **启动报错了？** 别慌，多半是首次启动较慢。点击「查看日志」打开日志文件夹（`%USERPROFILE%\.visionox\logs\`），发给管理员定位。大多数时候关掉重启一次就好。

**顺手做一件小事：** 首次默认浅色界面。左下角可切换 9 款配色主题。

> **老用户升级：** 覆盖安装会保留会话、模型配置、记忆和定时任务。升级前在「概览」里创建一次数据快照更安心。

---

## 第二步：30 秒认识主界面

第一天只需要知道两处：

**① 左侧导航栏**

| 工作区 | 高级 |
|---|---|
| **对话** -- 和 AI 聊天的地方 | 记忆、技能、工具、MCP、语义 |
| **会话** -- 找回历史对话 | **设置** -- 配模型的地方 |
| 文件、任务、概览 | |

**② 对话输入框下方的一排按钮**

`工作场景`（通用/编程）· `权限` · **`模型`（第三步要用）** · `工作空间` · `索引` · `技能`

---

## 第三步：配置模型--最关键的一步（约 3 分钟）

### 路径 A：有 JSON 配置文件（推荐，30 秒搞定）

1. 点击输入框下方的「**模型**」按钮
2. 点击「**导入模型配置**」，选中 JSON 文件
3. 涉及永久删除时会再问一次，放心确认
4. 点击「**检测全部模型**」，显示"可用"即配置完成 🎉

> 检测失败先别删。网络抖动会误判，重新检测一次；确认不行的再点「删除检测失败模型」（只删本轮确认不可用的）。

### 路径 B：只有一个 API Key

1. 打开「高级 -> 设置 -> **模型服务凭据**」
2. 选择服务商，粘贴 API Key（地址有变一起填 Base URL）
3. 点「**检测 API**」--通过后「保存凭据」才生效
4. 保存后点「**检测全部模型**」

> 检测失败不会覆盖旧配置，填错了重来即可。以后换 Key 也是同样入口。

---

## 第四步：发出你的第一句话（约 1 分钟）

在输入框里直接用大白话描述你想做的事：

- 📄 `帮我总结这份会议记录，并列出待办事项。`（把文件路径一起发给 AI）
- 📊 `分析这个 Excel 表中的异常数据。`
- 💡 `给我讲讲你能做什么，举三个适合我日常工作的例子。`

**立刻能用的小技巧：**

| 你想…… | 这样做 |
|---|---|
| 换个新话题 | 输入 `/new` 或点新建会话（旧内容不丢） |
| 让 AI 干不同类型的活 | 切换 `通用/编程` 场景；办公和设计任务直接在通用模式描述 |
| 查看所有本领 | 输入 `/help` |
| 粘贴截图或文件 | 直接 `Ctrl+V` |

---

## 第五步：选一个工作区（约 30 秒）

点击输入框下方的「**工作空间**」，选一个常用的项目目录。

- ✅ 切换工作区不会删除或移动原目录文件
- ✅ 切换在新建会话时才生效，不打断当前对话
- ✅ 不同工作区的记忆、技能、索引互相隔离

---

## 第六步：索引模式

| 模式 | 什么时候选 |
|---|---|
| **按需搜索**（新手推荐） | 普通聊天，需要查本地资料时让 AI 搜一下 |
| 自动召回 | 希望 AI 每次都主动参考工作区和知识文档 |
| 不使用 | 当前问题跟本地文件无关，更省资源 |

拿不准就选**按需搜索**，随时能改，选择会自动记住。

---

## 🎉 恭喜！入门配置已完成

**第一天值得一试的 5 件事：**

1. **让 AI 帮你写真文档**：在「通用」场景说 `帮我创建一个 Word 文档，写一份本周工作总结`
2. **定制界面配色**：左下角切换主题
3. **让 AI 记住你**：说 `请长期记住：我的称呼是××，我喜欢简洁的回答`
4. **试试定时任务**：在「任务」创建每日简报
5. **生成今日日报**：输入 `/report daily`

---

## 卡住了？新手自救清单

| 症状 | 怎么办 |
|---|---|
| 启动页报错 | 重启一次；仍不行点「查看日志」，日志在 `%USERPROFILE%\.visionox\logs\` |
| 模型检测全部失败 | 检查网络 -> 重新检测 -> 核对 Key 是否完整（别带空格） |
| AI 回答不了本地文件 | 确认把文件**路径**发给了 AI，且工作区选对了 |
| 处理 Word/Excel 报错 | 关掉正在占用该文件的 Office 窗口再试 |
| 删除的东西想找回来 | 会话和记忆删除后进**回收站**，30 天内可恢复 |

---

## 你的数据都在哪里

所有数据在 **`%USERPROFILE%\.visionox\`**（配置、会话、记忆、任务、日志）。在「概览 -> 备份与恢复」创建快照，恢复前会逐项校验和预览。
